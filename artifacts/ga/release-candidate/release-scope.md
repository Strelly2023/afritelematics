# NovaTech GA release candidate scope

Version: `2026.1.5-rc.1`

Commit: `82fabb8000bd5c4d512b307f0f61db09197af6a2`

The candidate covers the aggregate AfriTech API, public web, dashboard,
NovaCodePro portal, and governed NGINX configuration currently represented by
the production compose definition.

It does not authorize real customer identities or payments. Independent
product API deployment, mobile physical-device validation, external-provider
approval, comprehensive security testing, performance, recovery, evidence
signing, and organisational approvals remain mandatory NO-GO gates.

The tag identifies immutable source. It does not assert that artifacts have
been built, deployed, certified, signed, or approved.
