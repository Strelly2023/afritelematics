# NovaRide Disaster Recovery Guide

Use `scripts/novaride/run_dr_exercise.py` to generate machine-readable evidence packages.

Required evidence:

- exercise ID
- environment
- region
- start time
- detection time
- failover time
- recovery time
- measured data loss
- RTO/RPO result
- failed controls
- corrective actions
- logs, traces, and metrics snapshot
- operator approvals
- final verdict

Production destructive exercises require explicit authorization.
