# AfriPay Regulator Audit Package

Classification: external audit evidence package

This regulator audit package is evidence-only. It supports regulator and independent audit review of the signed proof bundle, public verification portal, and audit artifacts. It does not create settlement authority, execution authority, or regulatory approval.

Included materials:
- signed recursive proof bundle
- proof hash and Merkle roots
- downloadable JSON evidence
- downloadable PDF evidence
- third-party verification CLI output
- independent audit sandbox result
- trust-break evidence tests

Legal wording:
- The evidence package is intended for review and validation only.
- No part of this package should be interpreted as a claim of license, authorization, or live production settlement authority.
- Verification of these artifacts confirms internal consistency of evidence, not external regulatory approval.
