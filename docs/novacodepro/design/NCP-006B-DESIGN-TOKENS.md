# NCP-006B Design Tokens

Date: 2026-07-18

Supported token families include color, typography, spacing, size, border, radius, shadow, elevation, opacity, motion, duration, easing, breakpoint, grid, z-index, icon, and illustration.

Tokens are versioned, tenant-scoped, and validated for:

- unresolved references
- reference cycles
- duplicate token paths
- invalid values
- deprecated usage
- missing platform transforms
- tenant override violations

Approved tokens are preserved historically and may be exported as governed platform artifacts.
