# NCP-005 Traceability Architecture

The platform stores requirements and knowledge records in tenant-scoped repository collections. Traceability is represented as directed links between requests, requirements, acceptance criteria, architecture artifacts, code artifacts, tests, security controls, evidence, releases, and deployments.

Coverage calculations are derived from linked artifacts and exposed through the traceability API. Missing links reduce coverage and are reported as gaps rather than hidden.

Search and retrieval filter by authorization before returning results or citations.
