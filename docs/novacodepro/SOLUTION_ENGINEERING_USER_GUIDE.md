# Solution Engineering User Guide

Use Customer Solutions to move a request through:

1. Discovery
2. Requirements
3. Business analysis
4. UX/UI
5. Architecture
6. Engineering
7. Quality
8. Security
9. Compliance and risk
10. Release
11. Deployment
12. Acceptance
13. Operations
14. Support and evolution
15. Knowledge and evidence

The portal is role aware. Only windows and actions available to the current role
are rendered.
