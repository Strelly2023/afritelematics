# NCP-006B Design Security Model

Date: 2026-07-18

Design artifacts are governed by tenant, workspace, project, role, permission, classification, visibility, and retention controls.

The design surface fails closed for:

- cross-tenant access
- cross-workspace mutation
- unauthorized approval
- unapproved publication
- unverified external imports
- unsupported provider-backed generation

Research and participant data are treated as restricted where applicable.
