# NCP-005 Knowledge Security Model

- Tenant isolation is enforced in service context and repository filtering.
- Workspace scoping is preserved for requirements and knowledge records.
- Classification gates govern document visibility and retrieval.
- Approval is required before publication of governed content.
- Audit and evidence records are created for mutations and privileged reads.
- Cross-tenant search and retrieval are rejected.

External semantic/vector providers are optional and fail closed when unavailable.
