# NCP-007 User Guide

The Development Studio is the governed code-generation workspace for NovaCodePro.

Typical flow:

1. Open a Development Workspace.
2. Start a Development Session.
3. Create a Development Task.
4. Generate a governed change set.
5. Review validations, diff, and evidence.
6. Request and receive approval where required.
7. Prepare a commit or pull-request proposal.

The UI exposes repository browsing, validation, review, approval, command execution, and evidence views. Sensitive operations remain permission controlled.
