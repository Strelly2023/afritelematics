# NCP-006B User Guide

Date: 2026-07-18

Design Studio is the governed place to create experience briefs, research, personas, journeys, flows, wireframes, screen designs, design systems, tokens, themes, components, content, localization resources, accessibility requirements, and design baselines.

Use the design surface to:

- create and review design artifacts
- validate tokens, flows, screens, and accessibility requirements
- inspect traceability and coverage
- publish handoff packages
- compare versions and preserve history

External browser certification and live provider-integrations are not available in this environment.
