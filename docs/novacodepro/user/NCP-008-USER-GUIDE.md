# NCP-008 User Guide

The Operations Studio lives at `/novacodepro/operations`.

Primary views:

- Overview
- Environments
- Services
- Deployments
- Alerts
- Incidents
- Actions
- Approvals
- Observability
- SLOs
- Recovery
- Post-Incident Reviews
- Evidence
- Activity

Use the studio to inspect runtime state, request governed operational actions, track approvals, and review evidence.

Mutation remains policy-governed and approval-gated.
