# NCP-003 User Guide

What is available

- Open the workspace hub at `/novacodepro/workspace`.
- Switch workspaces from the workspace selector.
- Create projects from the workspace home or project list.
- Open project details to edit metadata, add milestones, work items, and risks.
- Create request drafts, upload attachments, submit requests, assign reviewers, comment, and transition requests.
- Archive projects and keep them readable while blocking further mutations.

Operational behavior

- Workspace selection updates the server-side session.
- Logout revokes the current session.
- Cross-tenant resources are hidden or rejected.
- Attachments that look like disguised executables are quarantined.

Known limitations

- Browser automation and physical device verification are not yet part of the committed repository evidence.
