# NCP-006A User Guide

Use Architecture Studio to:

1. open `/novacodepro/architecture`
2. create or select an architecture workspace
3. create an architecture model for a workspace
4. add components, interfaces, data, security and deployment records
5. run validation and fitness checks
6. create reviews, approvals and baselines
7. inspect traceability and impact analysis

The studio is governed and will reject cross-tenant or unauthorized access.
