# Solution Engineering Role Guide

- Customer: discovery, requirements review, acceptance, support, knowledge, evidence
- Business Analyst: discovery, requirements, business analysis
- Architect: architecture, approvals, evidence
- UI/UX Designer: UX/UI artifacts and design review
- Developer: engineering, workflow fabric, quality, evidence
- QA Engineer: test execution, quality review, evidence
- Security Engineer: security review, blocker visibility, evidence
- Compliance and Risk: compliance review, risk visibility, evidence
- Project Manager / Operations: release, deployment, operations, approvals
- Platform Administrator: full access across all solution windows
