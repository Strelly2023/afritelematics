# NovaRide screen catalog

- Rider: onboarding/authentication, home/map, destination/search, quote, booking, driver match, pickup, active trip, safety, payment, receipt, history, support, profile/settings.
- Driver: onboarding/KYC, vehicle/documents, availability, request, pickup/navigation, trip, safety, earnings, wallet, diagnostics/offline state, support, profile/settings.
- Operations: live dispatch, trip detail, incidents, support cases, payments/reconciliation, drivers/vehicles, fleet/corporate, regional configuration, resilience/replay, audit and SLO dashboards.

Every stateful screen requires empty, loading, stale/offline, permission-denied, validation, server-error, success and retry treatment where applicable.
