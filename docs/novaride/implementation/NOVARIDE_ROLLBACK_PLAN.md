# NovaRide GA programme rollback plan

## Repository rollback point

The programme starts at commit `94ba38da884ca9676cb500a7d32cac14ecefa055`, also present at `origin/feature/product-factory-enterprise-sdlc`. Pre-existing untracked artifacts are user-owned and must not be cleaned, overwritten, or included accidentally.

## Change strategy

- Use small NovaRide-only commits.
- Stage explicit paths; never stage the entire dirty tree.
- Preserve API routes, event schemas, deep links, and database compatibility.
- Put high-risk or incomplete capabilities behind fail-closed feature flags.
- Keep AI advisory and subordinate to deterministic policy.
- Keep live payments disabled until provider and governance gates pass.

## Rollback by layer

| Layer | Rollback mechanism | Verification |
|---|---|---|
| Documentation/config | Revert the individual programme commit | Validators and diff review |
| Web/mobile | Redeploy last immutable artifact digest | Smoke, auth and critical journey checks |
| API | Deploy previous compatible image | Contract and health checks |
| Feature | Disable server-side feature flag | Audit event and behavior check |
| Database | Prefer forward corrective migration | Constraint, row-count and integrity checks |
| Events | Stop new publisher; retain compatible consumers | Backlog, DLQ and replay verification |
| AI model | Kill switch or previous approved model | Deterministic dispatch remains available |
| Payments | Disable live provider; preserve reconciliation | Ledger and callback idempotency check |

## Stop conditions

Stop promotion on data corruption, cross-tenant access, identity bypass, duplicate/lost payment, unsafe dispatch, failed safety escalation, incompatible migration, invalid evidence, or artifact/commit mismatch.

## Recovery ownership

Engineering owns code rollback; database owners approve corrective migrations; operations owns deployment reversal; security owns containment; payments owns reconciliation; the release manager owns promotion state. Human approval records must identify the actual approver and cannot be generated by automation.
