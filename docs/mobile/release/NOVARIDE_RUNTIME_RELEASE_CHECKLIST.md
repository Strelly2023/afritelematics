# NovaRide Runtime Release Checklist

- Clean source
- Version increment
- OpenAPI/SDK compatibility
- Unit, integration, e2e, security, accessibility, and performance checks
- Clean build
- Signing
- Artifact inspection
- SHA256
- SBOM
- Provenance
- Immutable publication
- Public URL MIME and checksum validation
- Device/browser smoke test
- Rollback verification
- GA guard
- Real-payment guard

No fresh APK release is claimed by the runtime code changes alone.
