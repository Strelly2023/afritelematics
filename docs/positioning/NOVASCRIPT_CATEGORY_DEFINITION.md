# NovaScript Category Definition

NovaScript defines the category of Proof-Governed Engineering Intelligence.

| System | Primary Purpose |
| --- | --- |
| [GitHub Copilot](https://github.com/features/copilot) | Code assistance |
| [Cursor](https://cursor.com) | AI IDE |
| [OpenAI Codex](https://openai.com/codex/) | Software engineering agent |
| NovaScript | Engineering trust infrastructure |

## Category

```text
Proof-Governed Engineering Intelligence
```

## Definition

Proof-Governed Engineering Intelligence is infrastructure that generates engineering work, evaluates it through policy, issues deterministic receipts, certifies provenance, monitors assurance, explains decisions, and exposes portable verification artifacts to external parties.

## NovaScript Position

NovaScript is not only an AI coding assistant. It is a governed trust layer for software engineering decisions, audit packages, federation exchanges, certification programs, public trust portals, and architecture observability.

## What NovaScript Is Not

NovaScript can generate software.

Software generation is not its defining capability.

Its defining capability is generating, governing, verifying, assuring, certifying, and federating engineering trust.

NovaScript is not:

- only a code assistant
- only an AI IDE
- only a software engineering agent
- a replacement for legal audit
- a production authority by itself
- a substitute for proof truth
