# NovaRide Domain Authority Model

NovaRide owns mobility state: booking, trip, dispatch, route, pricing policy, fleet mobility, logistics execution, corporate transport, and transit journey integration.

NovaID owns identity, authentication, verification, RBAC/ABAC, device trust, and session risk.

NovaPay owns wallet ledgers, payment execution, settlement, payouts, refunds, lending, savings, insurance, and reconciliation.

NovaTrust owns signed evidence, receipts, immutable audit, replay, and evidence integrity.

NovaAI produces recommendations only.
