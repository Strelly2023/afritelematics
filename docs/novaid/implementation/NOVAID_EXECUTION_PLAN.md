3. Implement standards-library WebAuthn and OIDC authorization-code/PKCE ceremonies.

5. Connect all five apps and portals to generated contracts with accessibility tests.
6. Run real PostgreSQL/Redis/provider integration, concurrency, security, resilience, and physical-device suites.
7. Produce signed build, SBOM, deployment, operational, and independent assurance evidence; advance gates only from executed results.
