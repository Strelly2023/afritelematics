# Public Pilot Implementation

## Lifecycle

Private Development -> Internal QA -> Controlled Pilot -> Public Pilot -> Production Readiness Review -> GA

## Rule Summary

- Public users allowed only in approved regions.
- Selected external users only.
- Real payments only within pilot limits and with explicit approval.
- Real identity onboarding requires manual review.
- GA must remain false.

## Before PRR

- Monitoring verified.
- Incident response verified.
- Rollback verified.
- Compliance reviewed.
- Support staffed.
- Reconciliation clean.
