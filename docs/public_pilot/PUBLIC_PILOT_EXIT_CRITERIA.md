# Public Pilot Exit Criteria

Public Pilot can move to PRR only when:

- Invitation-based public pilot operations are in place.
- It is invitation-based and restricted to approved real users.
- Real trusted devices are registered and bound.
- Pilot geography is enforced.
- Transaction limits are enforced.
- Monitoring is live.
- Incident response is tested.
- Rollback is verified.
- Support is staffed.
- Reconciliation passes.
- Compliance is documented.
- NovaTrust evidence is generated.
- Readiness is READY_FOR_PRR.
- GA remains disabled.
