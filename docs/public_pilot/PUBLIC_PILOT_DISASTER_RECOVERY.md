# Public Pilot Disaster Recovery

## Recovery Controls

- Backup policy exists for runtime state and evidence.
- Restore validation is required before re-enabling pilot traffic.
- Rollback procedures cover API, APK, and release metadata.
- Emergency disable switches can halt payments or rides.

## Verification

- Restore a non-production snapshot.
- Validate evidence continuity after restore.
- Confirm monitoring and support are restored before re-entry.
