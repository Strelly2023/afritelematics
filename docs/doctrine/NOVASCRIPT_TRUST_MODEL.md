# NovaScript Trust Model

Trust in NovaScript is policy-driven, explainable, and portable.

## Inputs

```text
policy decision
trust score
risk score
certificate chain
assurance state
production evidence
federation exchange
```

## Outputs

```text
governance receipt
decision explanation
assurance drift result
portable verification package
adoption certification level
```

Trust does not depend on model claims. It is derived from governed inputs and emitted as deterministic artifacts.
